# Productivity Prediction of Garment Employees Using Machine Learning

## 1. Project Overview & Problem Formulation
This research project investigates the application of diverse machine learning models to predict the actual productivity of garment employees in Bangladesh. It addresses a supervised regression task using industrial floor-level production data.

## 2. Research Question
"To what extent do advanced tree-based ensembles outperform five machine learning families in predicting garment employee productivity under a strict zero-leakage pipeline and rigorous statistical validation?"

## 3. Dataset Information
- **Source:** UCI Machine Learning Repository (Productivity Prediction of Garment Employees)
- **Instances:** 1,197
- **Features:** 15 (Categorical and Continuous Numerical)
- **Target Variable:** `actual_productivity` (Continuous value range: [0.0, 1.0])

## 4. Planned Methodology
- **Phases:** EDA, Leakage-Free Preprocessing, Model Training (10 models across >=5 families), Cross-Validation, Statistical Significance Testing, and SHAP Explainability.
